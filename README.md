# BugTrack

**BugTrack** — мобильное приложение для учёта дефектов и организации работы с ними.

Проект объединяет основные этапы работы с багами: от создания записи и назначения исполнителя до отслеживания статуса и просмотра статистики.

В приложении можно управлять задачами, фильтровать дефекты по параметрам и анализировать результаты работы через графики и отчёты.

## ⚙️ Возможности

- Регистрация и авторизация пользователей.
- Создание и редактирование записей о дефектах.
- Назначение исполнителей, приоритетов и статусов.
- Фильтрация и сортировка задач.
- Статистика и графики.
- Экспорт отчётов в PDF и CSV.
- Уведомления и разграничение прав доступа.

## 🛠️ Технологии

| Компонент | Стек |
|---|---|
| Мобильное приложение | Flutter, Dart |
| Авторизация | Firebase Authentication |
| База данных | Cloud Firestore |
| Уведомления | Firebase Cloud Messaging |
| Управление состоянием | Provider |
| Статистика | fl_chart |

## 🔧 Как это устроено

BugTrack объединяет мобильный интерфейс Flutter и сервисы Firebase. Приложение отвечает за работу с дефектами и отображение данных, а Firebase — за авторизацию пользователей, хранение записей и уведомления.

Вместе эти компоненты формируют единое пространство для отслеживания ошибок и управления их исправлением.
